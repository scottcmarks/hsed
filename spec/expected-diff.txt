# The runtime oracle's expected differences (docs/spec-as-source.md section 5.5, M2a, M2b, M2d):
# every way the code hsedc generates from the PDF (every module of hsed/gen/Hsed/Gen/Core)
# differs from the hand transcription, the oracle's test fixture
# hsed/fixture/Hand/{TypeUIDs,TableUIDs,SpecialPurposeUIDs}.hs, one per line.
# hsed's EquivSpec fails on a missing or an extra line, on a line whose kind does not hold of the two
# sides, and on a line whose value is not the one it computes. The fixture's enumerations are compared
# under the generator's naming rule (EquivTH.asGenerated, design section 13.15: every value of a label
# that names several suffixed with it, the first included; dEnum left the first bare).
# In a reason, "hsed" means that 2019 hand transcription, hsed's library until M2d and the fixture
# since (the reasons date from M2a and M2b; the comments below say "the hand transcription").
#
#   subject | kind | value | reason
#
# subject: the definition, or the table whose caption differs. kind and value:
#   pdf-uid         the generated UID, the one the PDF prints
#   spacing         the same once spaces and underscores are dropped; the generated value
#                   (for an enumeration, +[constructors only generated] -[constructors only hand-written])
#   range-from-1    a range starting at 1, hand-written with _NA fillers from 0; as for spacing
#   typed-half-uid  a hand-written oth<T>/bth<T> not generated, its bytes those of h<T>; the hand-written value
#   new             generated, not in the hand transcription; its value (an enumeration's size, range and
#                   the FNV-1a digest of its constructor names, the names in hsed/gen)
#   unnamed         a hand-written UID of a table whose rows the PDF names nowhere (T239's Purpose column),
#                   not generated under its name, its value in the generated list of that table; the
#                   hand-written value
#   caption         generated / hand-written caption, spacing aside
